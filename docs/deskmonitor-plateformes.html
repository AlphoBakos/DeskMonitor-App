État au 2 octobre 2026. Version 1.5.0, testée sur un Mac Apple Silicon.

Windows : aucune version 1.5 n'a encore été construite ni testée. Le code est prêt et partagé avec macOS, mais l'installateur doit être produit sur un PC avec build.bat. Tout ce qui est marqué « à confirmer » côté Windows doit être essayé sur un vrai PC.

Installation

  • macOS Apple Silicon : le fichier DeskMonitor-1.5.0-mac-arm64.dmg, construit et testé sur ce Mac (30 étapes d'autotest, aucune erreur).
  • macOS Intel : produit par GitHub Actions (workflow « Installateur macOS »), non lancé pour la 1.5.
  • Windows 10 et 11 : build.bat sur un PC, puis publier_version.bat pour la mise à jour automatique.
