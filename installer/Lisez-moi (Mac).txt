DeskMonitor pour Mac
====================

INSTALLATION
1. Faites glisser l'icône DeskMonitor sur le dossier Applications.
2. Éjectez l'image disque.

PREMIER LANCEMENT
DeskMonitor n'est pas signé par Apple : macOS le bloque la première fois.
  - Ouvrez le dossier Applications, faites un clic droit (ou Ctrl + clic)
    sur DeskMonitor, puis choisissez « Ouvrir » et confirmez.
  - Sur macOS 15 (Sequoia) et plus récent : si ce n'est pas proposé, allez dans
    Réglages Système > Confidentialité et sécurité, puis cliquez sur
    « Ouvrir quand même » en face de DeskMonitor.
Les lancements suivants se font normalement.

UTILISATION
  - Paramètres : cliquez sur l'icône DeskMonitor dans le Dock, ou ⌘ + virgule,
    ou clic droit (Ctrl + clic) sur un widget.
  - Menu « Widgets » dans la barre des menus : afficher / masquer les widgets,
    actions rapides.
  - Fonds d'écran : la première fois, macOS demande l'autorisation de piloter
    « System Events » : acceptez pour que DeskMonitor puisse changer le fond d'écran.

Sur Mac, certaines fonctions de la version Windows ne sont pas disponibles :
écran de verrouillage personnalisé, libération de la RAM, carte graphique,
masquage des icônes du bureau.
